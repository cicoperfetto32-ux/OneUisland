# OneUisland — Dynamic Island для One UI 9

[English](README.md) | **Русский**

LSPosed-модуль (legacy Xposed API) для One UI 9 / Android 17. Заменяет капсулу Now Bar в статус-баре на динамический остров вокруг фронтальной камеры в стиле ColorOS 17 и HyperOS.

Готовая сборка — APK в разделе [Releases](../../releases).

## Что умеет

- Показывает в острове живые уведомления, как в Now Bar. Лайвы только для экрана блокировки (`android.ongoingActivityNoti.style ≥ 2`) не берёт.
- Показывает музыку, звонки, запись экрана и трансляцию.
- Делит остров на две части с жидкой перемычкой. Тап раскрывает стопку стеклянных карточек, которые «вытекают» из камеры.
- Плеер в стиле ColorOS 17: кнопки самого приложения и перематываемая полоса прогресса.
- Эквалайзер в капсуле реагирует на реальный звук.
- Показывает в карточке собственные RemoteViews-макеты приложений (например, навигатор).
- Остров фонарика: нажатие на фонарик включает и выключает его, перетаскивание по лучу выбирает ступень яркости, а сдвиг к фонарику выключает. Та же карточка заменяет уведомление фонарика в шторке.
- Остров диктофона Samsung: красная волна течёт справа налево рядом с таймером записи, в карточке кнопки паузы и остановки, после остановки на пару секунд показывается галочка сохранения. Если добавить «Диктофон» в scope модуля в LSPosed, волна идёт по реальному уровню микрофона.
- Секундомер показывает миллисекунды в острове, в карточке и в шторке. Уведомления с метриками показывают текст чипа от приложения.
- Положение острова: по центру или слева после часов (растёт только вправо и останавливается перед камерой). На планшетах и внутреннем экране складных есть вариант вокруг фронтальной камеры. У складных отдельные настройки для внутреннего и внешнего экрана. Остров слева может использовать блюр вместо чёрного фона.
- Свайп влево по капсуле сворачивает активность, свайп вправо возвращает её.
- Приложение при выходе улетает в остров. Для этого используется анимация One UI Home.
- Иконки статус-бара плавно пропадают, когда остров их перекрывает.
- Живые уведомления в шторке оформлены как тёмные стеклянные карточки острова: светлый текст, тонкий ободок и плотный фон при отключённом блюре. Сохраняются штатные макеты, раскрытие и действия приложений. Обычные уведомления и экран блокировки сохраняют системное оформление.

## Установка

1. Скачайте и установите APK из [Releases](../../releases).
2. В LSPosed включите модуль. Область: **System UI**.
3. Перезапустите System UI (перезагружать телефон не нужно), например так:
   `adb shell su -c "pkill -f com.android.systemui"`

## Сборка

Нужны JDK 17–21 и Android SDK (platform 36). Путь к SDK укажите в `local.properties`:

```
gradlew.bat :app:assembleDebug
```

APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

Проверка логики оформления шторки на подключённом Android 17 без установки APK и перезапуска SystemUI: `./tests/device/run.ps1` (PowerShell, JDK в `JAVA_HOME`). Подробности и список визуальных проверок — в `tests/device/README.md`.

## Структура

- `app/src/main/java/dev/flexy/dynamicisland/xposed` — точка входа и хуки SystemUI (`SystemUiHooks`).
  - `ShadeLiveCards` — оформление живых уведомлений в шторке (Samsung ongoing activity / AOSP promoted ongoing).
- `app/src/main/java/dev/flexy/dynamicisland/island` — остров:
  - `IslandView` — отрисовка, анимации, жесты;
  - `IslandController` — данные и сигналы;
  - источники данных: `OaSource`, `MediaSource`, `CastSource`;
  - блюр, эквалайзер и цели анимации выхода из приложения.
- `stubs` — заглушки Xposed API, используются только при компиляции.

## Плеер в шторке уведомлений

`ShadeMediaPlayer` подключает `IslandView.MediaBody` к `SecMediaControlPanel` только для `MediaType.ENR`. QS и плеер экрана блокировки остаются штатными. Данные и действия берутся из `MediaSource` по точному токену MediaSession, включая паузу, кнопки приложения и перемотку.

Высота ENR вычисляется по содержимому плеера. Ограничения `NotificationContentView` и высота Samsung media временно переопределяются только во время измерения этой строки. Фон создаёт сама SystemUI через `initBackground`/`initBlurBackground`: исключение медиа и colorized из обычного блюра снимается только для заменённой карточки; системные настройки прозрачности продолжают действовать.

При отсутствии активной сессии, на экране блокировки или с TalkBack используется штатный плеер. Применение обновления требует перезапуска только SystemUI, не телефона.
Нижняя подсветка MediaBody сохранена. Отключён только боковой радиальный notification accent One UI (`applyGradientBackground`) для этой карточки.


## Исправления 19.10.2026

- AOSP ProgressStyle (в том числе PaqaraPlace): исходные заголовок, текст и прогресс берутся из Notification, сохраняется цвет сегмента; карточка показывает значок слева и прогресс под описанием.
- В статус-баре сетевой тип (4G/5G) и уровень сотового сигнала затухают отдельно по собственным границам.
- LiveBridge: сопоставление по идентификатору копии от ключа исходного SBN, точным ключам из capsule-intent и резервному совпадению действий. Поддерживаются обычные уведомления и пустые групповые сводки. Уведомления только скрываются из списка SystemUI, без отмены в NotificationManager.
- Регрессии: `RegressionRunner`, инструкции в `tests/device/README.md`.

## Исправление накопительных лагов шторки 20.10.2026

`ShadeLayoutCallbacks` исправляет удаление одноразовых обработчиков оформления Samsung
FaceWidget (включая Google Sports). После замены штатной карточки на `LiveCardView` исходная
View отсоединяется. Её `getViewTreeObserver()` уже возвращает другой, пустой observer, поэтому
штатный callback удалял себя не из того списка и продолжал оформлять и измерять старую карточку
при каждой общей раскладке. Обновления уведомлений добавляли новые такие обработчики.

Для callbacks, захватывающих `FaceWidgetNotificationController`, удаление во время
`dispatchOnGlobalLayout` направляется в observer, который действительно вызывает callback.
Вложенные dispatch сохраняются в стеке на потоке; после завершения observer из стека удаляется.
Обычные слушатели и удаление вне dispatch сохраняют штатное поведение. Имена обфусцированных
классов AOD не используются. Частые временные логи замеров сборки карточек убраны.

`RegressionRunner` проверяет 64 последовательных обновления без повторных вызовов старых
callbacks, вложенный dispatch, штатное удаление и постоянные listeners.
